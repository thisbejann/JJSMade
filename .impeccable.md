# JJSMade Design Context

## Design Context

### Users
Single operator: a personal shopper/reseller who buys items (shoes, clothes, accessories) from China and resells to customers in the Philippines. Uses the app every single day to track orders through a pipeline (from purchase → QC → delivery), monitor profit margins, manage sellers, and review analytics. The audience is exactly one person — the builder — so the tool can be opinionated and personal.

### Brand Personality
**Dense, delightful, sharp.** This is a personal command center — not a generic SaaS dashboard. It should feel like it was designed by someone with taste, for someone with taste. Reference energy: Linear / Raycast — dark, information-dense, with moments of craft that make daily use enjoyable.

Three words: **Focused. Refined. Alive.**

### Aesthetic Direction
- **Theme**: Dark mode (currently: `#0b0c10` base, `#12131a` surface, `#e07850` warm coral accent) — lean into this, it's working
- **Reference**: Linear's density + Raycast's micro-interactions. Sharp edges, precise spacing, subtle animations that reward attention
- **Anti-references**: Generic SaaS dashboards, glassmorphism, neon glow effects, purple-to-blue gradients, hero metric grids where all 6 cards look identical
- **Typography**: Geist Variable is correct for the Linear feel — use it at multiple weights to create clear hierarchy
- **Motion**: Purposeful and restrained. Entrance animations on key data loads, meaningful transitions on important interactions (QC approve/reject, status changes). No decorative spinning or bouncing.
- **Layout**: Information density matters — this user can handle a packed dashboard. But visual rhythm through varied spacing prevents it from feeling overwhelming.

### Design Principles

1. **Important things demand attention** — profit, pipeline blockages, pending QC items should stand out immediately. Use size, weight, and color hierarchy — not everything can shout.

2. **Motion as feedback** — animate meaningful moments (approving a QC item, a status changing, data loading in). Keep decorative animation to zero. Every animation should convey state.

3. **Density with breathing room** — pack information in, but use deliberate whitespace to group related things and give the eye places to rest. Linear does this well: tight rows, generous section gaps.

4. **Craft in the details** — this is a personal tool used daily. Small moments of polish (hover states, smooth transitions, sharp typography) make the difference between "functional" and "delightful."

5. **Typography does the work** — rely on font weight and size variation to create hierarchy before reaching for color or icons. The reading order should be obvious at a glance.
